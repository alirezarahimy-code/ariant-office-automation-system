====================================================================
 گزینهٔ «حذف پایگاه‌داده موجود با همین نام» در فرم نصب  —  v3.4
====================================================================

تغییر
-----
در مرحلهٔ ۱ فرم نصب (اطلاعات اولیه سامانه) یک چک‌باکس اضافه شد:

   [ ] حذف پایگاه‌داده موجود با همین نام و ساخت از نو

- اگر تیک خورده باشد، هنگام «ساخت سامانه و ورود» (مرحلهٔ ۳) ابتدا
  دستور زیر اجرا می‌شود و سپس دیتابیس از نو ساخته می‌شود:
      DROP DATABASE IF EXISTS `نام_پایگاه_داده`
      CREATE DATABASE ... CHARACTER SET utf8mb4 ...
- اگر تیک نخورده باشد، رفتار قبلی حفظ می‌شود و فقط
  CREATE DATABASE IF NOT EXISTS اجرا می‌گردد (داده‌های موجود باقی می‌مانند).
- پیش از ادامه، اگر گزینه فعال باشد یک پیام تأیید هشدار نمایش داده
  می‌شود تا حذف تصادفی رخ ندهد.
- وضعیت چک‌باکس در طول مراحل نصب حفظ می‌شود (در session ذخیره می‌گردد).

هشدار
-----
با فعال‌کردن این گزینه تمام داده‌های دیتابیس هم‌نام (تیکت‌ها، کاربران،
شناسنامه‌ها و …) پاک می‌شود. برای نصب‌های معمولی تیک نزنید.

فایل‌های تغییر‌یافته
--------------------
install.php            (ذخیرهٔ گزینه در session + DROP DATABASE در مرحلهٔ ۳
                        + نمایش چک‌باکس و پیام هشدار و تأیید)
START-HERE.txt         (توضیح گزینه در بخش نصب)
00_CHANGELOG_INSTALL_DROP_FA.txt  (همین فایل)
