# فونت فارسی سامانه

فونت‌ها به‌صورت محلی و بدون وابستگی به اینترنت استفاده می‌شوند:

- `Vazirmatn-Regular.woff2`, `Vazirmatn-SemiBold.woff2`, `Vazirmatn-Bold.woff2`: متن اصلی رابط کاربری
- `Shabnam-Regular.woff2`, `Shabnam-Medium.woff2`, `Shabnam-Bold.woff2`: تیترها و عنوان‌ها
- `Vazir-Code.woff2`: کد، شناسه‌ها و مقادیر فنی
- `Samim-Regular.woff2`, `Samim-Medium.woff2`, `Samim-Bold.woff2`: فونت جایگزین آماده برای بخش‌های محتوایی آینده

ترتیب فعلی عمداً فقط Vazirmatn و Shabnam را در رابط اصلی فعال می‌کند تا ظاهر سامانه یکدست بماند.
