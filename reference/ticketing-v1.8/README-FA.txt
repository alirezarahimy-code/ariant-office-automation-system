هات‌فیکس حذف SOURCE_TABLE + گزارش غایبین + قالب

1) حذف SOURCE_TABLE
   - چند استراتژی SQL مستقیم (uid+date+time / فقط uid / کارت)
   - نرمال‌سازی تاریخ و ساعت عددی Access
   - فقط وقتی واقعاً ردیفی حذف شود موفق است

2) گزارش غایبین
   - در گزارش‌ها → نوع: «غایبین (سفارش دارند، فیش نگرفتند)»
   - سفارش‌های آن روز منهای کسانی که فیش چاپ‌شده دارند
   - با چاپ فیش از لیست غایب خارج می‌شوند

3) فرم طراحی
   - ذخیره قالب پیام درست می‌دهد
   - متن راهنما برای چاپ متنی Worker

نصب: جایگزین روی C:\xampp\htdocs\ticket
  Restart-ScheduledTask -TaskName "FoodTicket-Worker"
