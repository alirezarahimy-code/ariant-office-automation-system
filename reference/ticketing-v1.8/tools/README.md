# پشتیبان‌گیری عملیاتی

فایل `backup.ps1` از دیتابیس و پوشه پیوست‌ها نسخه پشتیبان می‌گیرد. رمز در خط فرمان نوشته نمی‌شود؛ اگر `ITSM_DB_PASSWORD` تنظیم نشده باشد، اسکریپت آن را به‌صورت امن می‌پرسد.

نمونه اجرای دستی در PowerShell:

```powershell
.\backup.ps1 -BackupRoot "D:\ITSM-Backups" -DbUser "itsm_backup"
```

برای تولید، کاربر دیتابیس اختصاصی با حداقل مجوز بسازید، پوشه مقصد را خارج از ریشه پروژه نگه دارید و Task Scheduler را برای اجرای روزانه تنظیم کنید. رمز فقط برای ساخت موقت فایل option در پوشه Temp استفاده و بلافاصله پاک می‌شود. برای اجرای بدون دخالت کاربر، `ITSM_DB_PASSWORD` را فقط در محیط امن حساب اجرای Task Scheduler تنظیم کنید. حداقل یک‌بار در ماه یک نسخه را روی سرور جداگانه Restore آزمایشی کنید.

فایل `config.php` شامل رمزهای اتصال است؛ آن را داخل backup عمومی قرار ندهید. در تولید با متغیرهای `ITSM_CONFIG_PATH` و `ITSM_INSTALL_LOCK_PATH` تنظیمات و قفل نصب را خارج از `htdocs` نگه دارید و یک نسخه رمزگذاری‌شده از آن را در محل امن سازمانی نگهداری کنید.

## برداشت شناسنامه از کامپیوترهای شبکه

`collect_server_inventory.ps1` برای استخراج سخت‌افزار سیستم اجراکنندهٔ پنل و کامپیوترهای انتخاب‌شدهٔ دامنه استفاده می‌شود. استخراج راه دور از WMI/CIM روی DCOM استفاده می‌کند؛ سرور پنل باید Windows و PowerShell داشته باشد، `shell_exec` در PHP فعال باشد، ارتباط RPC/DCOM در شبکه مجاز باشد و حساب تنظیم‌شده دسترسی Administrator محلی روی کامپیوترهای مقصد داشته باشد. اگر این پیش‌نیازها برقرار نباشند، وضعیت هر سیستم و پیام خطایش در صفحهٔ پیشرفت استخراج نمایش داده می‌شود.

`client-agent/Collect-Inventory.ps1` را روی Windows کلاینت با دسترسی عادی اجرا کنید. مقصد باید HTTPS باشد؛ مدیر سامانه توکن را فقط از `config.php` روی سرور می‌خواند و به‌صورت secure prompt وارد می‌کند. برای Task Scheduler، آن را فقط از محیط امن اجرای حساب سرویس با `ITSM_INVENTORY_TOKEN` فراهم کنید. Agent فقط مشخصات فنی و فهرست نرم‌افزارهای نصب‌شده را به `api/inventory.php` می‌فرستد و اطلاعات ثبت‌شدهٔ دستی را جایگزین نمی‌کند.
