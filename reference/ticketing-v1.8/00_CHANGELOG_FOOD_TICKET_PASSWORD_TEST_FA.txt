====================================================================
 آپدیت Worker v5 — رمز Access + تست پایش + ابزار CLI
====================================================================

۱) دکمه «تست پایش» در فرم پایش لحظه‌ای
   - رکوردهای دستی داخل SOURCE_TABLE را مثل تردد واقعی پردازش می‌کند
   - API موجود: POST /api/process

۲) رفع مشکل ذخیره/خواندن رمز Access (Not a valid password)
   - autocomplete=new-password روی فیلدهای رمز منبع تردد و سفارش
     (جلوگیری از autofill رمز ورود وب توسط مرورگر)
   - بررسی round-trip رمزنگاری هنگام ذخیره تنظیمات
   - خطای واضح اگر ciphertext با app.key فعلی decrypt نشود
   - تابع food_ticket_attendance_password()

۳) ابزار جدید: tools/set_attendance_password.php
   تشخیص و تنظیم مستقیم رمز بدون فرم وب:
     php tools/set_attendance_password.php --diagnose
     php tools/set_attendance_password.php "<رمز پیش‌فرض کارخانه>" --test

نصب Worker:
  - مسیر/رمز منبع تردد را درست ذخیره کنید (یا با CLI بالا)
  - ACE 2016 هم‌بیت با PHP
  - install-food-worker-SERVICE.ps1 با Run as Administrator
