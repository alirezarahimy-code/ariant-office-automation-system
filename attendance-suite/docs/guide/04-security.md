# سیاست‌های امنیتی سامانه

1. **احراز هویت:** ورود با محدودسازی نرخ (۵ تلاش ناموفق در ۵ دقیقه) + ثبت در گزارش دسترسی.
2. **نشست:** کوکی‌های HttpOnly + SameSite=Lax؛ با `SUITE_HTTPS=1` کوکی Secure و HSTS فعال می‌شود.
3. **مجوز:** همه نماها با `require_perm` محافظت شده‌اند؛ دسترسی غیرمجاز = 403 + ثبت رویداد.
4. **دامنه داده:** کاربر فقط داده محدوده نقش خود را می‌بیند.
5. **گزارش‌ساز:** فیلدهای سفید — بدون SQL دل‌بخواه.
6. **تنظیمات:** رمز/کلید در کد نیست؛ از متغیر محیطی (`SUITE_SECRET_KEY`) خوانده می‌شود.
7. **CSRF** روی همه فرم‌ها؛ اعتبارسنجی سمت سرور برای همه ورودی‌ها.
8. **گزارش دسترسی:** ورود/خروج، تلاش‌های ناموفق، دسترسی‌های ردشده، عملیات حساس.
