# گزارش‌ها و گزارش‌ساز

## گزارش‌های سیستمی
خلاصه ماهانه، تأخیر/تعجیل، اضافه‌کاری، درخواست‌ها، مانده مرخصی، کارکرد روزانه، تردد خام، وضعیت دستگاه‌ها، بازدیدکنندگان — همگی با فیلتر سال/ماه و خروجی CSV.

## گزارش‌ساز
در بخش «گزارش‌ساز» گزارش سفارشی بسازید:
- منبع داده: daily_record / punch / request
- ستون‌ها را از فهرست مجاز انتخاب کنید (جدا شده با ویرگول)
- مرتب‌سازی اختیاری

**امنیت:** انتخاب ستون فقط از فهرست سفید مجاز است؛ هیچ SQL دل‌بخواهی اجرا نمی‌شود.

## خروجی
دکمه «خروجی اکسل (CSV)» — نیازمند مجوز `reports.export` (با BOM برای نمایش درست فارسی).
