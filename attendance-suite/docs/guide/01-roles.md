# نقش‌ها و سطوح دسترسی

## نقش‌های پیش‌فرض
- **admin (مدیر سامانه):** همه مجوزها
- **hr_manager (منابع انسانی):** پرسنل، حضور و غیاب، درخواست‌ها، گزارش‌ها، دستگاه‌ها — دامنه «همه»
- **employee (کارمند):** مشاهده خودش + ثبت درخواست

## مدل دسترسی
مجوز = «ماژول × عمل» (view / add / change / delete / approve / report / export / manage)

**دامنه داده** (برای هر نقش در هر ماژول):
`self` فقط خودش | `dept` واحد خودش | `dept_tree` واحد + زیرمجموعه‌ها | `all` همه

## تأیید درخواست‌ها
هر درخواست را **مدیر مستقیم کارمند**، **جانشین‌های فعال او** یا دارندگان مجوز `requests.approve` می‌توانند تأیید/رد کنند.

## گزارش دسترسی
همه ورودها (موفق/ناموفق)، دسترسی‌های ردشده و عملیات حساس در «گزارش دسترسی» (core/audit) ثبت می‌شود.
