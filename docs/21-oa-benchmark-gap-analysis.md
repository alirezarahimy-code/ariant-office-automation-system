## ۱. معیارهای یک اتوماسیون تخصصی (از تحلیل سامانه‌های مرجع)

### ۱٫۱ دبیرخانه و مکاتبات (چارگون «مکاتبات اداری دیدگاه»، کارما، پیوند)

| قابلیت | توضیح حرفه‌ای |
|---|---|
| انواع نامه | وارده، صادره، **داخلی**، یادداشتی |
| نامه داخلی | ارسال بین واحدها/افراد **بدون عبور از دبیرخانه**، تحویل کارتابل گیرنده |
| نامه‌های مرتبط | **پیرو** (پیگیری نامه قبلی)، **عطف** (اشاره به سابقه)، **بازگشت** |
| طبقه‌بندی | عادی، محرمانه، خیلی محرمانه، سری + فوریت (عادی/فوری/آنی) |
| شیوه ارسال | دستی، پیک، ارباب رجوع، پستی، فاکس، رایانامه، کارتابل |
| رونوشت | چند گیرنده اطلاع‌رسانی با شرح رونوشت |
| پیوست | ضمائم الکترونیکی (تصویر/فایل) با کنترل حجم/فرمت |
| ارجاع | زنجیره‌ای، چندگانه، با دستور/مهلت، **بازپس‌گیری توسط ارجاع‌دهنده** |
| شماره‌گذاری | اندیکاتور خودکار به تفکیک سال/نوع/دبیرخانه + قالب شماره |
| الگوی نامه | متن‌های آماده پرکاربرد + «نامه مشابه» از نامه قبلی |
| هامش | یادداشت‌های غیررسمی روی کارت نامه |
| چاپ | سربرگ‌دار با امضا/مهر، رونوشت‌ها، نامه‌های مرتبط |
| کارتابل | تفکیک ورودی/خروجی/در انتظار، تفویض/جانشینی |
| ممیزی | تاریخ‌نگار کامل + حذف نرم |

### ۱٫۲ انبار (رایورز/سپیدار/مبنا-کلاس)

| قابلیت | توضیح حرفه‌ای |
|---|---|
| اسناد | رسید خرید، حواله فروش/مصرف، برگشت به تأمین‌کننده، برگشت از فروش، **انتقال بین انبارها**، تعدیل انبارگردانی |
| کاردکس | کارت کالا با موجودی پیوسته + ریزگردش در بازه |
| موجودی | لحظه‌ای به تفکیک انبار/کالا + کنترل موجودی منفی |
| انبارگردانی | شمارش فیزیکی + اعمال خودکار تعدیل |
| ارزش‌گذاری | قیمت واحد روی اسناد، **میانگین موزون**، ارزش موجودی |
| هشدار | حداقل موجودی/نقطه سفارش |
| چاپ | رسید/حواله با شماره مدرک و امضای تحویل |
| گزارش | گردش کالا در بازه، موجودی، ارزش، کالاهای زیر حداقل |

## ۳. آنچه در این فاز پیاده شد

### ۳٫۱ نامه‌های داخلی (اولویت اول)

- `InternalLetterForm` + صفحه `/letters/new/internal/` + پیوند «نامه داخلی» در منو
- گیرنده شخص (`to_user`) یا واحد (`to_department`) روی Letter — **تحویل مستقیم به کارتابل گیرنده** + اعلان
- کارتابل گیرنده نامه‌های داخلی باز را در تب «در انتظار اقدام» می‌بیند (`visible_letters` هم به‌روز شد)
- شیوه ارسال: کارتابل سیستم، دستی، پیک، پستی، فاکس، رایانامه

### ۳٫۲ نامه‌های مرتبط، هامش، نامه مشابه، بازپس‌گیری

- `LetterRelation` (پیرو/عطف/بازگشت) + فرم افزودن با شماره کارت نامه + نمایش در کارت و چاپ
- `LetterNote` (هامش) با نویسنده و تاریخ
- «نامه مشابه بساز» — کپی مشخصات به‌عنوان پیش‌نویس با پیوند خودکار «پیرو» (الگوی دیدگاه)
- `Referral.Status.CANCELLED` + دکمه بازپس‌گیری ارجاعِ در انتظار، فقط توسط ارجاع‌دهنده

### ۳٫۳ الگوی نامه

- `LetterTemplate` (عنوان، نوع، الگوی موضوع، متن) — دکمه‌های الگو در صفحه نامه داخلی متن را پر می‌کنند

### ۳٫۴ چاپ حرفه‌ای نامه

- بلوک‌های تازه در `letter_print.html`: فرستنده/گیرنده/شیوه ارسال (نامه داخلی)، نامه‌های مرتبط (پیرو/عطف/بازگشت)، فهرست رونوشت‌ها

### ۳٫۵ انبار

- `StockMove.category`: خرید، فروش، مصرف داخلی، برگشت از فروش/مصرف، برگشت به تأمین‌کننده، انتقال، تعدیل، سایر
- `StockMove.unit_price` + `weighted_avg_price` + `inventory_value` + صفحه «ارزش موجودی»
- `transfer()`: انتقال بین انبارها = حواله مبدأ + رسید مقصد با یک شماره مدرک (کنترل موجودی مبدأ)
- «ریزگردش در بازه» (`movement_report` با موجودی ابتدای بازه و پیوسته) + فیلتر انبار
- **چاپ سند رسید/حواله** با سربرگ، شماره مدرک و خطوط امضای تحویل

## ۵. آگاهانه کنار گذاشته‌شده (با دلیل)

| مورد | دلیل |
|---|---|
| چاپ گروهی/فکس خودکار | وابسته به زیرساخت فاکس سازمان؛ نیازمند نشست عملیاتی |
| چنددبیرخانه‌ای با اندیکاتور مستقل | مدل Office/NumberSequence از همین الان پشتیبانی می‌کند؛ UI سوییچ دبیرخانه در نسخه بعد |
| کدینگ درختی کالا/گروه‌بندی MPTT | فیلد category متنی فعلی برای مقیاس فعلی کافی است؛ ارتقا با مهاجرت داده |
| ضریب تبدیل واحد (بسته→عدد) | نیاز به بازطراحی مدل Item |
| اموال تثبیتی | زیرسامانه جدا (manifest پایان‌باز) |
| یادداشت اداری به‌عنوان نوع چهارم نامه | با همان نامه داخلی + هامش پوشش داده می‌شود |
