# سیستم طراحی رابط کاربری: رسمی، شیک، شرکتی

> سند طراحی بصری پلتفرم آرینت. این سند «قالب» خریدنی نیست؛ **زبان طراحی اختصاصی** سازمان است که همه زیرسامانه‌ها از آن پیروی می‌کنند. پیش‌نمایش زنده: `frontend/prototype/index.html`

---

# ۱. پنج اصل طراحی

1. **رسمی و آرام:** رنگ‌های مات سازمانی، بدون گرادیان، بدون انیمیشن پرزرق‌وبرق، بدون افکت‌های مد روز
2. **هم‌خانواده با اسناد سازمان:** همان قلم (وزیرمتن) و همان پالت رنگی سند‌های مصوب → یکی بودن برند در کاغذ و نمایشگر
3. **وضوح و چگالی اطلاعات:** جدول‌های اداری خوانا، سلسله‌مراتب بصری روشن، ارقام فارسی و تاریخ شمسی در همه‌جا
4. **احترام به وقت کارمند:** کارتابل = صف کار؛ اقدام اصلی هر صفحه همیشه پیدا و حداکثر با دو کلیک
5. **دسترس‌پذیری و چاپ:** کنتراست AA، کار با کیبورد، قالب چاپ A4 رسمی برای نامه‌ها

---

# ۲. چرا قالب آماده نه؟

| گزینه | ارزیابی |
|---|---|
| قالب تجاری فارسی | ریسک لایسنس، راست‌به‌چپ وصله‌شده، ظاهر تکراری و پر از اجزای اضافه |
| ادمین‌پنل‌های آزاد (AdminLTE/Tabler) | تمیز اما عمومی؛ برای کارتابل و نامه رسمی نیاز به جراحی سنگین |
| **سیستم طراحی اختصاصی (انتخاب ما)** | قلم و پالت سازمانی، اجزا دقیقاً برای اتوماسیون اداری ساخته می‌شوند؛ سبک‌وزن و قابل نگهداری |

پیاده‌سازی: CSS اختصاصی روی شبکه ۸ پیکسلی + قلم وزیرمتن؛ بدون فریم‌ورک سنگین. رابط کاربری فاز ۱ با **Django templates + HTMX** (سریع، ساده، کم‌فشار روی سرور) و API برای یکپارچه‌سازی‌ها.

# ۴. چیدمان

- نوار کناری راست (۲۶۰ پیکسل): منوی زیرسامانه‌ها با آیکن تک‌رنگ؛ بخش فعال با نوار teal
- سربرگ بالا: نشان سازمان + جست‌وجوی سراسری + کارتابل من + نام کاربر
- محتوا: ستون با عرض بیشینه ۱۲۰۰، فاصله‌ها مضرب ۸
- جدول‌ها: سر ستون سرمه‌ای، ردیف‌های یک‌درمیان روشن، بدون خطوط عمودی پررنگ

# ۵. فهرست اجزا

| جزء | قاعده |
|---|---|
| دکمه | اصلی سرمه‌ای، ثانویه دورخطی، خطر قرمز متن‌فقط؛ شعاع ۸ |
| نشان وضعیت | نقطه رنگی + متن؛ پس‌زمینه روشن (ثبت‌شده، در جریان، متأخر، محرمانه) |
| کارت | حاشیه ۱ پیکسل + سایه بسیار ملایم؛ تیتر ۱۵ بولد |
| فرم | برچسب بالا، ورودی ۴۰ پیکسل، تقویم شمسی درون‌خطی با آیکن |

| خالی/خطا | آیکن خطی + یک جمله راهنما + یک اقدام |

# ۶. ممنوع‌ها (ضد «جلف» و ضد «ولگرد»)

گرادیان، شیشه‌ماتی (glassmorphism)، شعاع بیش از ۱۰، سایه سنگین، قلم تزئینی، رقم لاتین، خاکستری روی خاکستری کم‌کنتراست، آیکن رنگارنگ، بنر تبلیغاتی، انیمیشن بزرگ‌نمایی خودکار.

# ۷. پیش‌نمایش و رویه

- پیش‌نمایش تعاملی: `frontend/prototype/index.html` را در مرورگر باز کنید (قلم از CDN بارگذاری می‌شود)
- هر صفحه جدید پیش از پیاده‌سازی، با این توکن‌ها و اجزا ساخته می‌شود؛ خروج از پالت فقط با تصویب
- بازنگری بصری در پایان هر اسپرینت با شما

**نسخه مصوب:** پیش‌نمایش «آرام و شفاف» (نسخه ۳ پروتوتایپ، `docs/prototype/index.html`) در تاریخ ۱۴۰۵/۰۷/۲۰ با تأیید کارفرما به‌عنوان **پایه اصلی نمایش سامانه** پذیرفته شد؛ همه صفحات فاز ۱ و بعد از همان توکن‌ها و اجزا ساخته می‌شوند.

**مبنای پیاده‌سازی توکن‌ها:** فایل `backend/static/css/platform.css` در ریپو — منبع حقیقت رنگ‌ها، قرص‌ها، جدول‌ها، برگه نامه و استپر (مطابق همین نسخه مصوب). همه صفحه‌های فاز ۱ با آن ساخته و آزموده شده‌اند.
