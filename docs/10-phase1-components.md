# ۴. ترتیب ساخت (اسپرینت‌های فاز ۱)

| اسپرینت | خروجی قابل دیدن |
|---|---|
| ۱ | مدل‌های داده نامه/ارجاع/رونوشت/پیوست + شماره‌گذاری + آزمون‌ها |
| ۲ | ثبت وارده + دفتر وارده + کارت نامه (رابط مصوب) |
| ۳ | کارتابل: صف‌ها، نمای نامه، ارجاع و پاسخ + اعلان‌ها |
| ۴ | صادره: پیش‌نویس، تأیید، امضا، PDF سربرگ‌دار + دفتر صادره |
