# ۲۶ — زیرسامانه بازرگانی: مطالعه شکاف و تحویل

> وضعیت: **نرم‌افزار کامل و اجراشده** — ۱۳ کلید `commerce.*` (همه toggle-able).
> مرجع رفتاری: سپیدار (تدارکات و خرید داخلی/خارجی + مشتریان و فروش)، راهکاران (تدارکات)، دیدگاه/چارگون، فکرگستر.

## ۱. چرخه‌های پوشش‌داده‌شده (رفتار مرجع)

**خرید (Procure-to-Pay):** درخواست خرید (اولویت/رویه جزئی-استعلامی-قراردادی) → استعلام بها → انتخاب برنده →
**سفارش خرید چندردیفی** (شماره خودکار PO-1404-0001) → **رسید انبار از سفارش** (سند رسید انبار در ماژول انبار) →
**فاکتور خرید** (کالا/خدمت/دارایی، تخفیف/اضافات/مالیات) → **تطبیق سه‌طرفه** سفارش/رسید/فاکتور → **تقسیط/تعهد پرداخت**.

**فروش:** پیش‌فاکتور → سفارش فروش → فاکتور فروش (حواله انبار خودکار) → برگشت از فروش (رسید برگشتی خودکار) + ابطال سند (بازگردانی موجودی).

**خرید خارجی:** پیش‌فاکتور ارزی، اعتبار/حواله ارزی، بارنامه، ترخیص گمرکی، هزینه‌های واردات به تفکیک مرحله، **فی تمام‌شده خودکار**.

**قراردادها:** شماره خودکار GC-1404-0001، نوع (خرید/فروش/خدمت)، طرف تجاری، مبلغ ضمانت.

## ۲. مدل‌های تازه

| مدل | نقش |
|-----|-----|
| `BusinessParty` | کارت تأمین‌کننده/مشتری (کد خودکار T-0001، شناسه/اقتصادی، شرایط پرداخت، سقف اعتبار، بانک/شبا) |
| `PurchaseRequestLine` | ردیف درخواست خرید |
| `InquiryLine` + ارتقای `Inquiry` | استعلام چندقلمی با پیوند تأمین‌کننده |
| `PurchaseOrder` + `PurchaseOrderLine` | سفارش خرید چندردیفی + پیگیری تحویل‌شده/فاکتورشده |
| `GoodsReceipt` | پیوند سفارش ↔ سند رسید انبار |
| `PurchaseInvoice` + `PurchaseInvoiceLine` | فاکتور خرید (کالا/خدمت/دارایی) |
| `PaymentSchedule` | اقساط/تعهد پرداخت (خرید و فروش) |
| `SalesDocument` + `SalesDocumentLine` | پیش‌فاکتور/سفارش/فاکتور/برگشت فروش |
| `ImportShipment` + `ImportCost` | محموله وارداتی + هزینه‌های تکمیلی |
| `CommerceSequence` | شمارنده سالانه اسناد |
| `Contract` (ارتقا) | شماره خودکار، نوع، ضمانت، طرف تجاری |

## ۳. یکپارچگی با انبار (یک سامانه، نه قطعات)

- رسید سفارش ← `StockDocument` رسید (کالا + قیمت از سفارش) + به‌روزرسانی «تحویل‌شده»
- فاکتور فروش قطعی ← سند حواله فروش انبار؛ برگشت ← سند برگشتی؛ ابطال فاکتور ← ابطال سند انبار
- مبدأ/مقصد همه اسناد با شماره سند بازرگانی ردیابی می‌شود

## ۵. نماها

داشبورد بازرگانی | درخواست خرید (لیست/ثبت/جزئیات + استعلام) | طرف‌های تجاری (کارت + اسناد مرتبط)
سفارش خرید (لیست/فرم چندردیفی/جزئیات/چاپ/رسید/تطبیق سه‌طرفه) | فاکتور خرید (لیست/فرم/جزئیات/چاپ/تقسیط/پرداخت)
اسناد فروش (لیست/فرم/جزئیات/چاپ) | خرید خارجی (لیست/فرم/جزئیات/هزینه/فی تمام‌شده)
گزارش خرید به تفکیک تأمین‌کننده | گزارش فروش به تفکیک مشتری | تعهدات باز | خروجی اکسل خرید
