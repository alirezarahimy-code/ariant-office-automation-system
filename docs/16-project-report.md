# ۵. فاز ۱ — دبیرخانه و کارتابل (تحویل این مرحله)

**مدل‌ها:** Office (چند دبیرخانه)، Letter (وارده/صادره/داخلی، ۱۰ وضعیت، ۳ درجه فوریت، ۴ سطح محرمانگی، مهلت شمسی)، NumberSequence (همزان‌امن با select_for_update)، Referral (زنجیره والد/فرزند)، Copy، Attachment (سیاست فرمت/حجم)، LetterEvent (ردگیری کامل)، LetterApproval (تأیید/امضا با تصویر)، Notification، Delegation، IntegrationUserMap، ExternalTicket.

**دسترسی:** سه سطح داده own/unit/all (الگوی تیکتینگ) + مجوز مستقل محرمانگی + زیردرخت سازمانی؛ ۶ گروه نقش پیش‌فرض (کاربر، کارشناس، مدیر واحد، دبیر، بازبین/امضا، مدیر ارشد) با دستور `setup_default_groups`.

**رابط (طراحی مصوب):** ورود؛ ثبت وارده/پیش‌نویس صادره با پیوست چندگانه؛ دفترچه‌ها با فیلتر و خروجی **اکسل راست‌به‌چپ**؛ کارت نامه = برگه A4 با سربرگ + استپر گردش + ارجاع/پاسخ/رونوشت/بایگانی + تاریخچه؛ کارتابل ۵ زبانه + ۴ KPI (در انتظار/نزدیک مهلت/متأخر/درصد پاسخ در مهلت)؛ اعلان‌ها؛ جانشینی؛ تب تیکت‌های من.

**گردش صادره:** پیش‌نویس → بازبینی → تأیید/امضا (سمت + تصویر امضا) → ارسال؛ **PDF سربرگ‌دار فارسی** (reportlab + reshaper/bidi + Vazirmatn) و نمای چاپ.

**عملیات:** `check_deadlines` (هشدار نزدیک‌مهلت/متأخر بدون تکرار)، `sync_tickets` (فقط‌خواندنی)، `setup_demo_data` (دموی کامل یک‌فرمانی)، پل SSO با توکن کوتاه‌مدت HMAC-SHA256 (قرارداد اثبات‌شده سرویس غذا).

**کیفیت:** تاریخچه آزمون‌ها ۲۵ → ۴۴ → ۶۴ → ۹۲ → ۹۵ (همه سبز)؛ آزمون بودجه کوئری برای فهرست‌ها؛ سیاست پیوست آزموده‌شده؛ محرمانگی بدون نشت در جست‌وجو/کارتابل/اعلان.
