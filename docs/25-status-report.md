## ۲. مرحله‌ی سامانه در نقشه راه

فاز ۰ (هسته) ✅ ← فاز ۱ (دبیرخانه + پل تیکتینگ) ✅ ← فاز ۲ (گردش کار، بایگانی، جلسات، وظایف، داشبورد) ✅ ← فاز ۳ و ۴ ✅ ← گام ۲ (لایه حرفه‌ای) ✅ ← **دبیرخانه کامل** ✅ ← **انبار کامل** ✅ ← فاز ۵ (اداری/مالی — بدون فیش حقوقی) ⏳ ← مهاجرت تیکتینگ ⏳ معلق به تصویب.

## ۳. ساخته‌شده

- **هسته:** کاربران/مجوزها (LDAP آماده)، اعلان چندکاناله fail-safe، کلیدهای قابلیت، تشکیلات، تقویم شمسی/تعطیلات، جانشینی، شماره‌گذاری، PWA.
- **دبیرخانه (کامل):** ثبت نامه چهارگانه، کارتابل، امضای چندنفره، نسخه/قفل، پاراف، رونوشت اقدام، ارجاع گروهی، دفتر اندیکاتور (اکسل)، اندکس، فاکس، پیک، پرونده اختیاری، SLA، رسید/تحویل، Word، جست‌وجوی سراسری، ثبت مقابل، تفویض امضا.
- **انبار (کامل):** سند چندردیفی (موقت/قطعی/ابطال/برگشتی، شماره سالانه)، کارت کالای حرفه‌ای (گروه درختی، مشخصات، تصویر، بارکد، چندواحدی، سریال/انقضا، محل استقرار، نقطه سفارش)، قیمت‌گذاری (لیست چندقیمتی، FIFO/LIFO/میانگین، دسته‌ای)، انبارگردانی (تگ، دومرحله، اکسل، سند اصلاحی)، گزارش‌ها/داشبورد/اکسل، دسترسی انباردار هر انبار + تفکیک تعدادی/ریالی، دوره مالی.
- **نسل اول (کارکردی):** گردش کار، جلسات/مصوبات، بایگانی/امحا، بازرگانی پایه، تردد، وظایف/تقویم، تیکت بومی + پل PHP، گزارش‌ساز.
- **زیرساخت:** سیستم طراحی v3، seedها، مهاجرت‌های مرتب، روش کار استاندارد (نیازسنجی → ممیزی شکاف → ساخت بدون وقفه → تست → اجرا → ادغام).

## ۴. باقی‌مانده

- **وابسته به زیرساخت:** فاکس‌سرور، SMTP واقعی، CA امضا، OCR، ECE، چاپگر لیبل.
- **به تصویب شما:** مهاجرت تیکتینگ PHP → بومی.
- **عمق‌بخشی نسل اول:** بازرگانی (نوبت فعلی)، گزارش‌ساز، منابع انسانی، مالی (بدون فیش حقوقی).
- **بهره‌برداری:** استقرار روی سرور سازمان + داده‌های واقعی.

## ۵. کیفیت و اجرا

- زنجیره اجرا: `migrate + seed_* + setup_*` از صفر تا سامانه آماده نمایش.
- روال آزمون: `python3 manage.py test` — ۳۹۸ سبز در زمان تهیه این گزارش.
