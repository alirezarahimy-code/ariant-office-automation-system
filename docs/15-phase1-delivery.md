## ۲. اجرای سریع (برای کارفرما)

```bash
git clone -b arena/bfc4d9a2-ariant-office-automation-syste https://github.com/alirezarahimy-code/ariant-office-automation-system
cd ariant-office-automation-system/backend
python3 -m venv .venv && source .venv/bin/activate   # یا هر محیط پایتون ۳.۱۱+
pip install -r requirements/base.txt
python3 manage.py migrate
python3 manage.py setup_demo_data     # داده نمایشی + گروه‌های نقش + تیکت‌های نمونه
python3 manage.py runserver           # → http://127.0.0.1:8000/
```

**کاربران نمایشی** (رمز = نام‌کاربری + 1234):
`dabir` دبیر | `modir` مدیر واحد | `karshenas` کارشناس | `emza` بازبین/امضا | `modir-arshad` مدیر ارشد | `karbar` کاربر عادی

**آزمون‌ها:** `python3 manage.py test` → ۹۵ آزمون

## ۳. گروه‌های نقش (تطبیق از واژگان تیکتینگ)
کاربر، کارشناس، مدیر واحد، دبیر، بازبین/امضا، مدیر ارشد — ساخته خودکار با `setup_default_groups`. سطوح داده: خود / واحد و زیرمجموعه (MPTT) / همه + مجوز جداگانه محرمانگی.

## ۴. عملیات
- زمان‌بندی پیشنهادی: `check_deadlines` هر ۶ ساعت؛ `sync_tickets` هر ۱۵ دقیقه (cron یا celery beat — سلری در وابستگی‌هاست)
- پل تیکتینگ: متغیرهای env — `TICKET_BRIDGE_URL`، `TICKET_BRIDGE_SSO_KEY` (چرخش‌شده)، و برای DB زنده: `TICKET_DB_HOST/PORT/NAME/USER/PASSWORD` با **کاربر فقط‌خواندنی**. تا فراهم‌شدن دسترسی، منبع fixture فعال است.
- تولید: PostgreSQL از طریق env، `collectstatic`، `ENFORCE_HTTPS`، چرخش `SECRET_KEY`
